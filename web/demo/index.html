fidddle in the browser

Polyphonic pitch detection for string instruments. One detector gives two kinds of result: continuous pitch signals that drive Web Audio nodes, and MIDI-style note events. This page shows both.

1. Input and instrument

Press Start. A microphone should be a plain instrument signal; the page switches off echo cancellation, noise suppression and automatic gain, which would distort it. Use headphones with a microphone to avoid feedback.

2. Continuous: pitch signals drive oscillators

Each voice's frequency and on/off gate are audio-rate signals connected straight to an oscillator's frequency and an amplifier's gain. Nothing is sent as a message.

3. MIDI: note events

Note-on and note-off events carry the note number, velocity and times. They can drive a built-in synth, a MIDI device, or your own code.

How this page uses the library

const fid = await Fidddle.create(ctx, { profile: 'cello', quality: 'efficient', trackFrames: true });
source.connect(fid.node);

// continuous: voice 0 pitch drives an oscillator, its gate drives the amplifier
fid.signals.connectFrequency(0, osc.frequency);
fid.signals.connectGate(0, amp.gain);

// MIDI: note events
fid.events.addEventListener('noteon', e => console.log(e.detail.note, e.detail.velocity));
fid.events.connectMidi(midiOutput, { channel: 0 });
fid.events.activeNotes;   // sounding notes, sorted by pitch
